# Guía práctica de ArcPy: análisis de migración de aves

Este repositorio contiene el desarrollo de una guía práctica para aprender y documentar el uso de ArcPy a partir de una aplicación funcional en ArcGIS Pro. El caso de estudio corresponde al análisis de trayectorias migratorias del ganso de frente blanca y su relación con variables de viento.

## Objetivo

Documentar el funcionamiento del script `goose_tool.py`, configurado como herramienta de geoprocesamiento en ArcGIS Pro, para ejecutar filtros espaciales, temporales y atributivos, generar análisis estadísticos y exportar productos cartográficos.
